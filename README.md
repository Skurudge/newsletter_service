# Курсовой проект: Сервис управления рассылками "NewsletterService"

## Описание проекта:
Веб-приложение на фреймворке Django, предназначенное для автоматизации email-маркетинга [config:settings, mailing:models]. Сервис позволяет пользователям управлять базами клиентов (получателей), создавать текстовые шаблоны писем, группировать их в кампании рассылок и отслеживать детальную статистику отправлений с фиксацией ответов почтовых серверов [1-6]. 

В проект интегрирована полноценная ролевая модель доступа (RBAC), система верификации аккаунтов по email, инструменты низкоуровневого кэширования агрегированных данных и локальная адаптивная верстка на Bootstrap 5 [7-10].

## Архитектура и функциональные возможности (10 задач):
1. **Управление клиентами (Задача 1):** Полноценный CRUD-интерфейс для добавления, изменения и удаления получателей рассылки с уникальной валидацией Email [mailing:models, mailing:views].
2. **Управление сообщениями (Задача 2):** Конструктор шаблонов писем с разделением тем и текстового содержимого сообщений [mailing:models, mailing:views].
3. **Управление рассылками (Задача 3):** Создание кампаний с указанием временных диапазонов (`start_time` / `end_time`) [mailing:models, mailing:views]. Реализован метод `update_status()` для автоматического динамического пересчета статусов («Создана», «Запущена», «Завершена») при вызове `get_object()` [mailing:models, mailing:views].
4. **Отправка сообщений по требованию (Задача 4):** Сервисный слой `services.py` для ручной инициации email-кампаний с проверкой временных интервалов и пакетной отправкой через `send_mail()` [mailing:services, mailing:views].
5. **Логирование попыток (Задача 5):** Автоматическая фиксация каждой отправки в модель `MailingAttempt` с сохранением даты, статуса («Успешно» / «Не успешно») и сырого ответа от почтового сервера [mailing:models, mailing:views].
6. **Главная страница и дашборд (Задача 6):** Вывод ключевых метрик платформы: общего числа рассылок, количества активных кампаний и объема уникальных клиентов в базе [mailing:views, mailing:templates:mailing:home].
7. **Аутентификация и верификация (Задача 7):** Кастомная модель пользователя `User` с авторизацией по `email` [users:models]. Автоматическая отправка писем с уникальным токеном для подтверждения регистрации [users:views] и функционал сброса пароля на случайную буквенно-цифровую комбинацию [users:views].
8. **Статистика и отчеты (Задача 8):** Сбор истории логов для формирования прозрачной аналитики по доставке писем [mailing:models, mailing:views].
9. **Ограничение прав доступа (Задача 9):** Обычные пользователи управляют строго своими объектами [mailing:views, mailing:forms]. Создана системная роль **Менеджер**: имеет право просматривать все рассылки/клиентов/пользователей, а также мгновенно блокировать учетные записи и отключать подозрительные рассылки без права удаления чужого контента [mailing:views, users:views, mailing:forms].
10. **Кэширование производительности (Задача 10):** Интеграция СУБД **Redis** в качестве кэш-бэкенда [config:settings]. Метрики главной страницы агрегируются и кэшируются в Redis на 15 минут, исключая лишнюю нагрузку на PostgreSQL [mailing:views].

## Системные требования и окружение:
* **Python** версии 3.13 [config:settings]
* **Django** версии 6.0+ [config:settings]
* **PostgreSQL** (хранение бизнес-логики) [config:settings]
* **Redis** (кэширование данных) [config:settings]
* **Пакетный менеджер:** Poetry [config:settings]

## Инструменты контроля качества кода (Линтеры):
В проекте настроена строгая автоматическая проверка синтаксиса и стилистики Python-кода:
* `black` — форматирование кода под единый стандарт (длина строки 120 символов) [config:settings].
* `isort` — автоматическое упорядочивание импортов [config:settings].
* `flake8` — проверка стилистических ошибок и сложности алгоритмов.
* `mypy` — статический анализ строгой типизации данных.

## Инструкция по установке и запуску:

1. **Клонируйте репозиторий проекта:**
   ```bash
   git clone https://github.com/Skurudge/newsletter_service
   ```
2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```
3. **Настройте файл переменных окружения `.env` в корневом каталоге:**
   ```env
   SECRET_KEY="ваш_сгенерированный_секретный_ключ"
   DEBUG=True
   DB_NAME=newsletter_db
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_от_postgres
   DB_HOST=127.0.0.1
   DB_PORT=5432
   REDIS_LOCATION=redis://127.0.0.1:6379/1
   ```
4. **Убедитесь, что серверы СУБД PostgreSQL и Redis запущены локально.**
5. **Выполните миграции базы данных:**
   ```bash
   poetry run python manage.py makemigrations users mailing blog
   poetry run python manage.py migrate
   ```
6. **Запустите сервер разработки Django:**
   ```bash
   poetry run python manage.py runserver
   ```
7. **Откройте проект в браузере:** Перейти по адресу `http://127.0.0.1`.
